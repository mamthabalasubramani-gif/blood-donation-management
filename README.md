Android application for donor registration, blood requests and donor search using Java and SQLite.
# Blood Donation Management System

## Project Overview
The Blood Donation Management System is an Android application developed to connect blood donors with individuals who need blood. It helps users register as donors, submit blood requests and search for suitable donors.

## Technologies Used
- Java
- XML
- SQLite
- Android Studio

## Features
- User Registration and Login
- Donor Registration
- Blood Request Management
- Donor List
- Search Donors by Blood Group and City
- User Profile

## Database
SQLite is used to store donor information and blood request details.

## Purpose
The main objective of this project is to make blood donor information easier to manage and help users find potential blood donors.

## How to Run
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or compatible device.
